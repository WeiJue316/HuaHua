日期：2026-09-24

## 审计范围

- 基准数据集：`pilot_questions.v1.jsonl`（冻结版，未修改）
- 候选来源：OpenAlex 引用图正向/反向扩展
- 候选总数：10 题 × 25 条 = 250 条
- 候选表：`gold-candidates-csai_001.md` 至 `gold-candidates-csai_010.md`

## 审计方法

1. 模型初审：判断候选是否直接回答某个子问题，并在每次采纳时逐字摘录摘要原句。
2. 程序核验：采纳引文必须逐字出现在对应摘要中，否则打回。
3. Codex 复核：逐题检查采纳引文的语义匹配、子问题归属，并抽样复核拒绝理由。
4. 结构修复：不完整句子扩展为完整原句，超长单句上限由 400 调整为 600 字符。
5. 去重：按规范化标题检测同一论文的预印本/会议版重复。
6. 无摘要候选：统一标为“暂不纳入”，不伪造证据，也不记为“不相关”。

## 方法与证据边界

本审计由模型初审和 Codex 复核完成，不是两名独立人类标注者的一致性研究。因此：

- 可用于后续工程迭代、回归测试和消融实验，但论文中不得把它表述为“人工金标”。
- 若论文要用它证明最终检索/证据链质量，应至少加入独立人工抽检，并报告抽检比例与一致率。
- “暂不纳入”只表示当前源站没有可核验摘要，不表示论文主题不相关。
- 所有采纳引文均通过逐字核验；核验命令为：
  `uv run python scripts/apply_gold_review.py --worksheet-dir evaluation/review --dry-run --freeze-cache`
